# Pawloop Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task-by-task.

**Goal:** Build a working pet GIF showcase and sharing community.
**Architecture:** Vite React frontend and Express API backed by node:sqlite; same-origin session authentication, private upload storage, transactional growth rewards.
**Tech Stack:** Node 24, React 19, Vite 7, Express 5, SQLite, sharp, Playwright.
**Spec:** docs/superpowers/specs/2026-11-12-pawloop-design.md

## Global Constraints

- Default English, settings offer English and simplified/traditional Chinese with fallback.
- 15 MB decoded GIF validation; pending moderation before publication or upload rewards.
- Invite reward 50 on first approved upload, once, daily cap 10; daily check-in 10, signup 20, approved upload 25, first approved upload bonus 30.
- No default credentials, no email verification claim, no forum implementation this release.

## Review Focus

- Duplicate/repeated requests never double-credit points.
- Pending GIFs cannot leak to anonymous visitors.
- Bad files and malformed input produce bounded failures.
- Language persists across reload without translating user content.
- Narrow viewports and keyboard dialogs remain usable.
